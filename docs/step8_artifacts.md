# Step 8.1: ML Artifact Serialization

## 1. Purpose
In Steps 5 and 6 V2, anomaly detection models (Isolation Forest, PCA, Statistical Baseline) and score normalizers were dynamically fitted on the development dataset during every batch run. 
For Step 8 (Real-Time Inference), refitting models on live streams is computationally prohibitive, breaks state causality, and introduces instability. 

To enable strict streaming, we must **freeze and save (serialize)** the exact model artifacts, parameters, and thresholds generated from the development set, so they can be loaded instantly into memory for real-time inference without requiring the original training dataset.

## 2. What is Saved?
We extract and persist the following artifacts using `joblib` into `data/artifacts/`:
1. `statistical_baseline.joblib`: Contains the 99.5th percentile threshold (e.g. 14.6753) for Z-score deviations.
2. `pca_detector.joblib`: Contains the fitted scikit-learn `PCA` model, its selected components (e.g. 38), the internal `BaselinePreprocessor` (scaler/imputer), and the 99.5th percentile threshold (0.8543).
3. `isolation_forest_detector.joblib`: Contains the fitted `IsolationForest` model, its preprocessor, and threshold (0.5436).
4. `hybrid_engine_v2.joblib`: Contains the Step 6 V2 `HybridAnomalyEngineV2`, including the `ModelEvidenceNormalizerV2` parameters (min/max bounds for evidence mapping) and the family-specific thresholds (Sudden Event and Persistent Fault).

A manifest file `data/artifacts/manifest.json` acts as a registry tracking the dataset used, random seeds, and specific threshold values to ensure configuration drift does not occur.

## 3. How to Load
The models are simply loaded into memory at the start of the streaming pipeline:
```python
import joblib

stat_model = joblib.load('data/artifacts/statistical_baseline.joblib')
pca_model = joblib.load('data/artifacts/pca_detector.joblib')
if_model = joblib.load('data/artifacts/isolation_forest_detector.joblib')
engine = joblib.load('data/artifacts/hybrid_engine_v2.joblib')
```

## 4. Equivalence Verification
To guarantee the serialized artifacts correctly capture the frozen Step 6 V2 intelligence without silent changes:
1. We loaded the `joblib` artifacts.
2. We generated predictions on a 1,000 row deterministic sample from the full evaluation set (`data/processed/aws_synthetic_features.csv`).
3. We compared the numeric (`final_anomaly_score`, `anomaly_confidence`), categorical (`fault_type_hint`), and boolean (`anomaly_flag`) outputs against the original CSV generated by the batch pipeline.
4. The outputs matched perfectly (numeric equality within $10^{-5}$ relative tolerance).
