# Synthetic Anomaly Injection

## 1. Why Synthetic Anomalies are Needed
The historical Max Planck Weather dataset used in this project represents real-world AWS operations, including natural sensor drifts, noise, and communication gaps. However, because it is an unlabeled dataset, it lacks explicit ground-truth labels identifying exactly when and where hardware faults occurred. 

To train, evaluate, and benchmark anomaly detection algorithms reliably, we need exact ground truth. Synthetic anomalies provide controlled ground truth for evaluation by overlaying realistic artificial sensor/data faults on top of normal historical weather observations. 
**Note:** Synthetic anomalies provide controlled ground truth for evaluation but may not represent every real-world AWS sensor failure.

## 2. Available Anomaly Types
Our framework supports the following physical and data transmission faults:
1.  **Spike:** A sudden, very short duration burst of impossible/improbable values (simulates electrical glitches).
2.  **Drift:** A gradual, cumulative shift in sensor readings over time (simulates calibration decay).
3.  **Frozen (Stuck):** A sensor repeatedly reports the exact same value for hours (simulates mechanical jamming or buffer freezing).
4.  **Offset (Bias):** A sudden, persistent shift in baseline reading (simulates physical jarring or partial short).
5.  **Abnormal Noise:** Increased variance obscuring the underlying signal (simulates electromagnetic interference).
6.  **Missing Data:** Complete loss of signal represented by `NaN`s (simulates communication/power failures).
7.  **Multivariate Inconsistency:** An anomaly injected strictly into one variable while preserving the natural temporal behaviour of the others, enforcing the necessity of cross-variable context.

## 3. Anomaly Generation Approach
Anomalies are generated by `simulator/generate_dataset.py`, which utilizes the `AnomalyInjector` class.
- The script iterates over the clean dataset (`aws_clean.csv`).
- It randomly selects injection windows that are confirmed "safe" (avoiding existing missing data and large time gaps).
- It injects faults mathematically (e.g., adding a linear space array for drift, or picking a random constant for frozen).
- It generates explicit row-level labels marking exactly which observations were modified and why.

## 4. Default Parameter Ranges
Parameters are defined in `simulator/config.py`:
- **Spikes:** 1 to 3 observations. Magnitudes up to 6°C, 30mbar, 30% RH.
- **Drift:** 6 to 24 hours. Drifts up to 10°C, 40mbar, 40% RH.
- **Frozen:** 6 to 24 hours.
- **Offset:** 3 to 12 hours. Shifts up to 8°C, 25mbar, 35% RH.
- **Noise:** Standard deviations up to 1.5°C, 4mbar, 10% RH.
- **Missing:** 30 minutes to 6 hours.

## 5. Random Seed
Reproducibility is strictly enforced using a fixed numpy random seed:
```python
RANDOM_SEED = 42
```
Running the generation pipeline multiple times will produce exactly identical synthetic datasets.

## 6. Ground-Truth Labeling
Two types of labels are generated:
- **Row-level:** `data/processed/aws_synthetic_anomalies.csv` contains `is_anomaly`, `anomaly_type`, `affected_sensor`, and `anomaly_id` columns appended directly to the observations.
- **Event-level:** `data/processed/labels_aws_synthetic_anomalies.csv` contains a summary of every distinct anomaly event, its start/end boundaries, and its type.

## 7. Dataset Generation Commands
To generate a small development dataset (~15,000 rows):
```bash
python simulator/generate_dataset.py --dev
```

To generate the full evaluation dataset (~420,000 rows):
```bash
python simulator/generate_dataset.py
```

## 8. Validation Commands
To validate dataset integrity, label accuracy, and generate sample plots:
```bash
python simulator/validate_dataset.py
```
Validation plots are output to `docs/validation/`.

## 9. Limitations
- Synthetic anomalies are generated using linear/gaussian models and may not capture complex nonlinear hardware breakdown behaviors.
- The injector assumes the underlying baseline data is "normal", which means some synthetic anomalies might occasionally overlap with natural (but unlabeled) extreme weather events.
